# error_desc:
The local expansion and the conclusion that $\omega_k'/(2\omega_k)\sim 1/[4(\eta-\tilde\eta)]$ are correct for a simple zero of $F=\omega_k^2$. The contour prefactor $\pi/3$ is also consistent with the stated Hankel/steepest-descent treatment if the full simple-turning-point branch structure is used. However, the derivative at the selected lower-half-plane turning point has the wrong sign: for $\tilde\eta=\eta_e+1/(a_eH_I)-i m/(kH_I)$ one finds $1-a_eH_I(\tilde\eta-\eta_e)=i m a_e/k$, hence $F'(\tilde\eta)=+2i k^3H_I/m$, not $-2i k^3H_I/m$. This is not merely a square-root branch convention; it changes the local phase orientation. There is also a notation inconsistency: the steepest descent variable is defined as $u$, but the subsequent differential and integral use $\nu$.
 # fix_instructions:
Correct the derivative evaluation to $$F'(\tilde\eta)=\frac{2a_eH_I m^2a_e^2}{[1-a_eH_I(\tilde\eta-\eta_e)]^3}=+2i\frac{k^3H_I}{m}.$$ If using the upper-half-plane turning point instead, state that explicitly; only then the sign would be negative. Also use one consistent local variable, e.g. $$u=-\frac{4i}{3}\sqrt{F'(\tilde\eta)}z^{3/2},\qquad \frac14\frac{dz}{z}=\frac16\frac{du}{u},$$ and write the local contour integral as $\frac16\int_{\mathcal H}du\,e^u/u$. The magnitude prefactor may remain $\pi/3$ under the stated full Hankel/Stokes prescription.
